# Stroke dataset

Download **Stroke Prediction Dataset** by Kaggle user `fedesoriano`:
https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset

Place `healthcare-dataset-stroke-data.csv` in this directory before running the code.
The CSV is excluded from Git so this repository contains code only.

The local dataset used for the existing analyses contains 5,110 records and 12 columns.
SHA-256: `644d473b05d2797006bd94865e4f8bb057f0c721617911613c82c8fcfc707420`.
The Kaggle version number and original collection period were not recorded.
Population representativeness and original collection provenance are unverified.
Consult the dataset page for its usage terms.
